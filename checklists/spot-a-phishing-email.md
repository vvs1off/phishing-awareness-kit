# How to spot a phishing message — one-page cheat sheet

> Print me. Pin me up. Share me.

## Pause. Then check these six things

| Check | Ask yourself |
|-------|--------------|
| **1. Sender** | Is the real address (not the display name) from a domain I know? Any look-alike letters? |
| **2. Urgency / fear / reward** | Is it rushing me, threatening me, or offering something too good? |
| **3. Links** | Where does it *really* go when I hover (or long-press)? Does it match who it claims to be? |
| **4. Attachments** | Was I expecting it? Odd type or double extension (`.pdf.html`, `.exe`)? |
| **5. The ask** | Passwords, codes, payments, gift cards, bank-detail changes, remote access? |
| **6. Tone and details** | Generic greeting? Unusual wording? Or suspiciously perfect and personal? |

## Safe default
1. **Don't click, don't reply, don't open.**
2. **Verify** using a bookmark, the official app, or a phone number you already have.
3. **Report** it (see [how to report](how-to-report.md)).

## Golden rules
- Nobody legitimate asks for your **password or one-time code**.
- Money or bank-detail requests are **always verified by phone**.
- A prompt you didn't start is a **Deny**.
- If you slipped: **tell someone right away.** Speed matters more than perfection.
